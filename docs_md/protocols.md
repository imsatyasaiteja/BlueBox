# Protocols Guide

BlueBox uses simplified aircraft-style traffic for local demos. The goal is not to emulate a certified aircraft system. The goal is to show how evidence from multiple domains can be normalized, scored, logged, and replayed.

## Supported Evidence Families

| Evidence family | Source format | Typical domain |
|---|---|---|
| Cabin network traffic | PCAP and CSV | `cabin` |
| Maintenance network traffic | PCAP and CSV | `maintenance` |
| AFDX-style traffic | PCAP and CSV | `afdx` |
| ARINC 429-style words | CSV | `avionics` |
| Logger security events | JSON/SQLite | `integrity` |

## PCAP and Network Fields

PCAP-derived rows use familiar network fields:

| Field | Meaning |
|---|---|
| `src` | Source IP address |
| `dst` | Destination IP address |
| `protocol` | TCP, UDP, ICMP, or domain-specific value |
| `port` | Destination port |
| `packet_size` | Packet size in bytes |
| `frequency` | Approximate packet frequency |
| `domain` | Cabin, maintenance, or AFDX |

Common anomaly signals:

- Packet size spike
- Frequency burst
- Unexpected port
- Unexpected protocol
- Cross-domain movement
- Repeated traffic pattern

## ARINC 429 Fields

ARINC 429 demo rows represent simplified 32-bit avionics words.

| Field | Meaning |
|---|---|
| `src` | Bus identifier, such as `BUS_A` |
| `dst` | Label identifier, such as `LABEL_206` |
| `label_octal` | ARINC label in octal form |
| `ssm` | Sign/status matrix |
| `sdi` | Source/destination identifier |
| `data` | Encoded data field |
| `parity` | Parity bit |

Common anomaly signals:

- Unexpected label
- Invalid or unusual SSM
- Parity issue
- Abnormal data value
- Repeated command-like behavior

## Integrity Events

Integrity events are generated by the logger layer rather than by traffic files.

Examples:

- Blocked delete attempt
- Blocked update attempt
- Forced corruption detection
- Recovery ledger restore
- Chain verification failure

For DB mutation attempts, BlueBox should show:

```text
source = attacker IP
target = targeted sequence number
```

Example:

```text
203.0.113.45 -> SEQ #355
```
